Four steps to a first RGB payment on the BLAKE2b testnet4. Each ticks itself off.

    Coins

    01 / FUND

    Send txbt4 to this address. Each coin can carry one RGB asset.

    YOUR RECEIVING ADDRESS

    Assets

    Receive

    03 / INVOICE

    Transfers sent to this wallet over Nostr are taken in as they arrive while this tab is open, and when it refreshes.

    Pay

    04 / TRANSFER

    Send tBTC

    05 / SPEND

    Spends only coins that carry no asset and aren't waiting for an invoice to be paid, so no RGB asset can be lost here.

    Or prepare spare coins

    Spare coins are for invoices and new assets: each coin carries at most one asset.

    This wallet

    06 / PROTECT

    Explorer: . Add ?api=<Esplora URL> to use another, or ?wallet=<name> for a separate wallet in this browser.

    The whole-wallet backup holds everything, encrypted with your passphrase: the seed and the assets. Make a new one after each payment. The seed alone brings back the keys but not the assets; the asset backup alone brings back the assets to a wallet that already has the seed.

    This deletes the seed and every asset file from this tab. Without a backup of the seed, the coins and assets are gone.
